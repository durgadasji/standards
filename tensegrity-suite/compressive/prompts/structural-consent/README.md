# Prompts

Paste-and-go prompts for using standards in this repository with any AI assistant.

## Structural Consent Legibility Standard

| Prompt | Use it on |
|---|---|
| [Structural Consent Audit](structural-consent-audit-0_1_1.md) | Governance documents, participation terms, consent architecture |

Each file contains a self-contained prompt. Copy everything in the file, paste it into any AI chat (Claude, ChatGPT, Gemini, or similar), and attach the document or describe the system you want audited. The AI will produce a failure map organized by criterion, most consequential deficits first.

No prior knowledge of the standard is required. The prompts carry everything the AI needs.
