# Prompts

Paste-and-go prompts for using standards in this repository with any AI assistant.

## Adverse-Signal Engagement Principle Core Standard

| Prompt | Use it on |
|---|---|
| [AI Adverse Signal Audit](ai-adverse-signal-audit-0_1_1.md) | AI system designs, model documentation, feedback architectures |
| [Organizational Adverse Signal Audit](organizational-adverse-signal-audit-0_1_1.md) | Governance documents, policies, process descriptions |
| [Regulatory Compliance Adverse Signal Audit](regulatory-compliance-adverse-signal-audit-0_1_1.md) | Compliance frameworks, regulatory submissions |

Each file contains a self-contained prompt. Copy everything in the file, paste it into any AI chat (Claude, ChatGPT, Gemini, or similar), and attach the document or describe the system you want audited. The AI will produce a failure map organized by criterion, most consequential deficits first.

No prior knowledge of the standard is required. The prompts carry everything the AI needs.
