# Prompts

Paste-and-go prompts for using standards in this repository with any AI assistant.

## Sensemaking Standard

| Prompt | Use it on |
|---|---|
| [Sensemaking Presence Assessment](sensemaking-presence-assessment-0_1_2.md) | Coordination systems, organizations, or processes |

Each file contains a self-contained prompt. Copy everything in the file, paste it into any AI chat (Claude, ChatGPT, Gemini, or similar), and describe the coordination system you want assessed. The AI will produce a presence map: whether the structural conditions the standard specifies are present, and what the growth edges are.

No prior knowledge of the standard is required. The prompts carry everything the AI needs.
